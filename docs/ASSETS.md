# Asset provenance

The airport geometry, suitcase meshes, lighting, favicon and interface are original procedural code in this repository. No airport photographs, Apple artwork, proprietary 3D models or audio are shipped to players.

Local reference screenshots in `design/references/` are third-party study material, excluded from Git and deployment. Their source URLs are documented in DESIGN_REFERENCES.md; no redistribution license is asserted for those captures.

Application captures in `design/captures/` show the original application. Runtime dependencies retain their own licenses: React, Three.js, React Three Fiber/Drei and Vite use MIT; Lucide icons use ISC; Inter fonts use SIL Open Font License 1.1. Package distributions include their respective license notices. The project's MIT license does not replace those licenses.
